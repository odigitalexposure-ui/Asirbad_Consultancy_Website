## Website Pages
1. **Home (`/`)**: High-impact editorial hero, company introduction, service highlights, practice principles, consultant introduction, contact CTA, and interactive location preview.
2. **About (`/about`)**: Company philosophy, Gobinda Kumar Mukherjee's consultant profile with authentic placeholder, four-step advisory methodology, and closing CTA.
3. **Services (`/services`)**: Eight structured service categories (Income Tax, ITR Filing, GST Consultancy, GST Return Filing, Documentation, Tax Planning, Business Support, and Personal Consultation) with checklists, target client profiles, and direct enquiry routing.
4. **Contact (`/contact`)**: Dual-column layout with verified contact cards, direct telephone and WhatsApp links, validated enquiry form (with Indian phone number validation and direct client transmission), and embedded Google Maps iframe with GPS directions.

## Local Development
```bash
# Install dependencies
npm install

# Start Vite dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
